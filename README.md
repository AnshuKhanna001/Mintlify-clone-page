# Mintlify Landing Page Clone

**Mintlify landing page clone** built using **HTML and CSS**.
This project recreates the modern style UI of Mintlify with a focus on layout and clean component structure.

## 📸 Preview

![Project Preview](assets/preview_page.png)

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* Google Fonts (Inter & Geist Mono)

---

## Features

* Modern SaaS landing page design
* Fixed blurred navigation bar
* Hero section with background graphics
* Company logos grid
* Feature card sections
* Enterprise feature section
* Carousel-style showcase section
* Multi-column footer
